QIXTON SCROLL-STORY HOMEPAGE

Files:
- index.html
- qixton_logo.png

Upload both files to the ROOT of your GitHub repository.
Then go to GitHub -> Settings -> Pages -> Deploy from a branch -> main -> /(root).

This version uses GSAP + ScrollTrigger from a CDN for the scrolling animation.
It also has a fallback if GSAP fails to load and respects reduced-motion settings.

Before launch:
- Replace hello@qixton.com in index.html if that mailbox is not active.
- Replace any service copy you want to change.
- The growth numbers inside the animated visual are illustrative only and are explicitly labeled as such later on the page.
