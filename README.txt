QIXTON 3D WEBSITE PACKAGE
=========================

This ZIP contains the complete static Qixton website.

MAIN CHANGES
- The homepage hero was rebuilt into independent layers.
- Interactive 3D glass Q globe with a miniature city and rotating light rings.
- Service cards float and tilt on desktop.
- Five interactive 3D service scenes: Web Design, SEO, Social Media, Paid Ads and AI Search.
- Scroll-driven service switching and clickable scene tabs.
- A Pause Motion control and reduced-motion support.
- Responsive fallback graphics for devices without WebGL.
- Existing pricing, founder, guarantee, contact and service pages are included.

HOW TO USE
1. Extract all files without changing the folders.
2. Upload the extracted contents to the root of your current hosting or GitHub Pages repository.
3. Keep assets/ and vendor/ in place.
4. Open index.html through a web server. The website is static and needs no build command.

IMPORTANT
- The package is ready for static hosting.
- The contact form retains the current FormSubmit setup.
- The Google Analytics tag from the current website is retained.
- Three.js is included locally in vendor/ so the 3D scenes do not depend on a CDN.
